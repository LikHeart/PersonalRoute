# 🐱 ТПУ · Мой маршрут

> Персональный маршрут студента ТПУ: задачи, дедлайны, карьерная цель и ИИ-помощник — в одном спокойном пространстве.

---

## 📖 О проекте

Веб-приложение на **Spring Boot + Thymeleaf** для студентов ТПУ. Помогает разгрузить голову: пользователь пишет задачи обычным текстом, а ИИ-кот раскладывает их по срокам, подсказывает шаги и помогает двигаться к карьерной цели.

**Стек:** Java · Spring Boot · Spring AI (Ollama) · Spring Security · JWT · PostgreSQL · Thymeleaf · Jsoup

---

## 🗂 Структура проекта

### ⚙️ Конфигурация

| Файл | Назначение |
|------|-----------|
| `ChatClientConfig.java` | Настраивает `ChatClient` с инструментом `WebTools` по умолчанию. |
| `SecurityConfig.java` | Отключает CSRF, разрешает публичный доступ к фронтенду и API, включает stateless-сессии. |
| `application.properties` | Настройки Ollama, почты Gmail, PostgreSQL, Thymeleaf и JWT. |

### 🎛 Контроллеры

| Файл | Назначение |
|------|-----------|
| `ChatController.java` | Принимает сообщения пользователя и возвращает ответ ИИ с системным промптом и `ChatTools`. |
| `MailController.java` | Регистрация, вход и отправка кода подтверждения на почту. |
| `WindowController.java` | Отдаёт Thymeleaf-страницы: лендинг, авторизация, дашборд, события, чат, профиль. |

### 🧠 Сервисы

| Файл | Назначение |
|------|-----------|
| `JwtService.java` | Генерация, извлечение email и проверка JWT-токенов. |
| `MailService.java` | Отправка HTML-письма с 5-значным кодом и его проверка (хранится 10 минут). |
| `UserService.java` | Проверка занятости email, регистрация и поиск пользователя по почте. |
| `ChatTools.java` | Инструмент `askWithButtons` для вопросов с кнопками-вариантами. |
| `WebTools.java` | `fetchPageContent` (парсинг страницы через Jsoup) и `searchWeb` (поиск в DuckDuckGo). |

### 🗃 Сущности и репозитории

| Файл | Назначение |
|------|-----------|
| `User.java` | JPA-сущность пользователя (id, имя, email, пароль, дата создания). |
| `UserRepository.java` | Репозиторий с методами `findByEmail` и `existsByEmail`. |
| `PersonalRouteApplication.java` | Точка входа Spring Boot приложения. |

### 🎨 Стили

| Файл | Назначение |
|------|-----------|
| `common.css` | Переменные цветов, reset, кнопки, логотип, скроллбар. |
| `auth.css` | Стили страницы входа/регистрации: сайдбар, карточка, табы, валидация. |
| `chat.css` | Стили чата: контейнер, сообщения, поле ввода, кнопки. |
| `dashboard.css` | Стили главной: приветствие, карточка цели, AI-инпут, канбан. |
| `events.css` | Стили страницы событий: фильтры, пустое состояние. |
| `layout.css` | Сайдбар, шапка, навигация, профиль для app-страниц. |
| `profile.css` | Стили профиля: карточка студента, статистика, график, карьера. |

### 🧩 Скрипты

| Файл | Назначение |
|------|-----------|
| `auth.js` | Переключение вход/регистрация, валидация, отправка кода, регистрация и логин. |
| `chat.js` | Отправка сообщений, печать ответа, парсинг `[SUGGESTIONS]` и кнопок `askWithButtons`. |
| `common.js` | Текущая дата, переключение фильтров, скролл наверх по логотипу. |
| `landing.js` | Скролл наверх по клику на логотип на лендинге. |
| `user.js` | Подстановка имени/инициалов из localStorage, скрытие гостевых элементов, выход. |

### 🖼 Шаблоны Thymeleaf

| Файл | Назначение |
|------|-----------|
| `auth.html` | Страница регистрации/входа с формой и кодом подтверждения. |
| `main.html` | Лендинг: hero-блок, превью дашборда, карточки возможностей. |
| `layout.html` | Общий каркас app-страниц: сайдбар, шапка, баннер гостя, контент. |
| `head.html` | Фрагмент `<head>` со стилями и prefetch. |
| `header.html` | Фрагмент шапки: хлебные крошки, дата, аватар. |
| `sidebar.html` | Фрагмент бокового меню с навигацией и профилем. |
| `chat.html` | Фрагмент чата: сообщения и поле ввода. |
| `dashboard.html` | Фрагмент главной: канбан-доска и AI-инпут. |
| `events.html` | Фрагмент событий: фильтры и пустое состояние. |
| `profile.html` | Фрагмент профиля: статистика, график, карьерная карточка. |
| `error.html` | Страница ошибки с кодом и ссылкой на главную. |
